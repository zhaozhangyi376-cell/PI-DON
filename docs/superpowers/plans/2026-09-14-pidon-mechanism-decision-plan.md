## 一、审核依据与结论边界

主要依据：本地论文全文 `paper_text.txt` 的 III-B/III-C/IV-A/IV-B 与原 PDF；`PAPER_FIRST_REVIEW.md`；`REPRODUCTION_LOGICAL_CHAIN_20260914.md`；#221 的 `evidence/2026-09-14_acceptance_review/acceptance_review.json`；当前 `dco.py`、`gen_data.py`、`pidon_solve.py` 的实际输入归一化、位置适配、损失、参数更新和场更新逻辑。旧文档和代码注释中的因果结论不自动采信。

本次为只读源码/证据审查，没有重跑训练或重新测出实验成绩。下列数值引用已有磁盘验收，不是本次独立运行所得。

### 1.1 从第一性原理分解目标

1. **算子学习：** 第一阶段从采样场及几何信息预测解析旋度。问题是“没见过的场与网格上是否仍准确”，不是训练 loss 是否下降。旋度是线性、局部微分运算；神经网络能拟合它并不自动意味着比已知差分更有用。
2. **顺序物理求解：** 第二阶段在自身当前场上，用离散 Maxwell/Yee 残差更新网络，再用网络预测更新场。此过程不需要事先生成真实场轨迹标签，但每步的 Yee 旋度目标已可由当前场计算。准确拟合这一目标能支持接近参考解；它没有自动带来计算加速，也不自动改变显式推进的稳定条件。
3. **预训练的因果价值：** 在相同架构、容差、优化器和算力下，预训练是否比随机初始化少训练、少失败？论文 Fig.8 本身就比较了这两种初始化。累计 loss 只能辅助解释；实际更新数、耗时与相同场精度才回答收益。
4. **训练后价值：** 论文 IV-B 与后续器件章节还涉及训练后评估、改变时间步及重复参数计算。逐步重训成功，不能替代训练后复用成功。后者才直接关系到重复仿真是否划算。作者项目页也把训练后泛化、重复分析列为主要用途：https://shutong.space/Projects/ 。

从离散误差看，若网络旋度为 `C_D = C_Yee + δC`，一次 E/H 更新的新增误差分别含 `dt/ε·δC_H` 与 `-dt/μ·δC_E`，再通过后续耦合累积。相同旋度相对误差，可能对应不同的场增量误差和长期相位偏差。因此既需要拟合指标，也必须测场与源外传播。

第一阶段解析导数与第二阶段离散导数也不同：沿一个方向，交错中心差分对平面波的符号为 `2 sin(kh/2)/h`，解析导数为 `k`。二者低波数接近但不完全相同。预训练迁移需要实测，不能以解析 curl 小误差直接宣布离散闭环成立。

## 二、新计划的原则与共同验收

### 2.1 明确改变、明确保留

- **改变：** 43/96及其他远期参考状态的“从主权重新拟合全部通过”，不再是新顺序轨迹的必要前置。它们保留为离线压力测试。真实顺序任务每一个实际半步仍必须通过。
- **改变：** 本轮首要产物是带随机初始化对照的连续轨迹，不是再选一种末层或二阶优化方法。先使用纯 Adam 基线，便于解释预训练与时间继承的作用。
- **保留：** L4/base32/direct、cellsize/RMS、h_shift=True、独立H/E、n=31、50mm空气PEC腔体、dt=3.075ps、当前硬源/测量协议。它们是明确声明的实现变体，不能写成已忠实还原全部论文细节。
- **保留：** Adam lr=3e-4，每目标最多500更新、不重置逐步Adam状态；非零目标 R<1e-4，零目标沿用既有固定绝对尺度规则；每目标360秒；失败不得推进。新轨迹从零场与原始合法初始化开始，不恢复任何旧失败权重。不开LS/LBFGS、学习率/尺度/结构扫描。
- **保留：** 旧 G2/G3 的场、波形、频谱门槛。没有因为最近失败而放宽场标准。
- **不要求：** 每个短程成绩都先满足全部8192工程归档功能。只认证本次实际会走到的路径；若之后要恢复长跑，必须先验证该恢复路径。

这是待执行方案中的新实验定义；实际执行前必须将参数、门槛、种子和预算排他写入新目录并记录真实创建时间。旧实验不能据此重新评级。

### 2.2 结果分层

- **S1（算子学习的有限范围机制证据）：** 新的未见样本上逐样本逐分量宏nMAE≤1e-2，整体旋度相对L2的样本90分位≤5%；立方与迁移组分别判断，完整列出个体结果。此为本次研究筛选标准，不是论文MRE门槛，也不是改判旧P5的1e-3门槛。MRE Eq.(5)、近零分量绝对误差另列。16个样本仅作筛选，不宣称广泛总体统计证明。
- **S2（沿用旧G2）：** 零場顺序1024接受步；每个适用半步R合格；活跃时刻能量加权Q≤5%、各有效场分量nMAE≤1e-2、源外波形误差≤5%、弱场A_fixed≤1e-3；300/600/900切片齐全；H对齐半时间层。64/128只是检查节点，不另起新任务。
- **S3（沿用旧G3）：** 同轨迹8192步且保持S2；五模频率相对解析≤0.5%、相对匹配FDTD≤0.2%、可解析峰谱幅≤1dB、活跃段能量偏差≤10%。未解析峰记不可验收，不能移动取峰窗口凑答案。
- **B（预训练收益筛选）：** 同一接受步数、同精度下，预训练相对随机初始化的在线总更新时间和更新数均至少降低20%，且两次随机初始化对照方向一致；预训练自身耗时另外计入总成本。20%是提前声明的工程筛选裕度，不是论文指标或显著性结论。若随机臂先失败，只能报告有限预算下成功率/可达步数优势，不能算无限加速比。
- **U（最低复用筛选）：** 最终训练权重冻结，真实重新从初始场演化；同腔体/同dt先验收，再测高斯脉冲宽度乘1.2、峰值时刻与幅值不变的新波形。128步筛选后在可用预算内至1024；使用S2场标准但没有在线拟合门。另测源幅0.5仅作齐次性控制，不能计入U的泛化成绩：当前输入RMS归一化与逆变换本身就使正幅缩放近似结构成立。新波形通过仍不足以声称几何/材料泛化。失败不能直接归因于论文，因为作者训练后权重使用方式尚有歧义。

活跃/弱场划分、分母、体积权重、探针、mask等直接复用v1计划的数值定义并在新manifest展开，不得由DCO结果决定有效时段或剔除点。源后观测窗口用参考源曲线预先固定。每个分量保存分子和分母；零/近零不强行算相对误差。论文MRE与nMAE全程分栏。

### 步骤4：只对主臂的首次失败做一次有针对性的鉴别

**理由：** 失败后应判断“定义错、优化难，还是成本不划算”，不是把测试清单再扩一轮。

- [ ] 从保存输入/靶值/参数纯前向复算最终R和分量绝对误差；核实近零分量、目标支持、归一化逆变换及输入是否丢了必要邻点。利用已有精确几何控制，不把精确核安装进DCO当解。
- [ ] 读取已记录的0/10/50/100/200/500更新曲线及实际时间；只作平台/持续下降描述，不将平台等同理论下限。
- [ ] 若明确发现关键接口错误，提出独立修复方案后再安排新的实验；不在本轮边改边续失败轨迹。若接口无错，结论为本实现/预算不可行，提交作者澄清材料并结束本次训练链。

**交付：** 一页首次失败诊断。取消“所有可想象原因都要测完”的目标。没有判决性证据就写原因未定。

### 步骤5：成功后验证预训练收益和更长物理过程

**理由：** 一次短轨迹可能由特定初始化碰巧完成；多次传播反射才检验场解而非源点拟合。

- [ ] P通过128后，随机臂第二个seed20260915重复共同128窗口；P相同确定性协议只需一次磁盘纯推理验收，不重新训练制造样本数。随机两seed只是最低筛选，不能给总体显著性结论。
- [ ] 计算B：同窗、同精度在线训练时间与更新数，预训练历史总成本单列；随机臂失败用截断状态报告。
- [ ] 同一P轨迹在剩余预算允许下到1024，读取300/600/900场切片，验收S2。不得用每次重新参考场暖启动的多个短窗拼接成长轨迹。
- [ ] 保留旧计划的额外延长停损：1024末128步RMS-Q不得高于前128步两倍；它只是延长风险信号，不是普遍稳定性定理。

**预期：** 第一次形成有限范围“学到算子→在线适配→源外正确传播”的闭合证据链，并知道预训练是否省事。

**停止：** S2失败或资源不足，保留已接受步和误差，长程NOT_RUN。S2成功但B无优势，承认求解机制可行、预训练收益未证实。

### 步骤6：在扩展8192之前，先筛选最低训练后复用价值

**理由：** 单次逐步拟合已知Yee目标往往昂贵；是否能在后续问题上减少训练，直接决定研究投入价值。

- [ ] 冻结失败时明确：这是“最终权重冻结”这一具体解释失败；作者若实际使用时间索引权重，则属于不同机制，不能代替作者下结论。先要求明确评估算法，再计划复杂几何/材料迁移。

**涉及文件：** 复用预测及场更新接口，增加明确禁训练的评估入口；不把此入口推定为作者真实评估程序。图脚本与源数据一起保存。

### 步骤7：仅在前述证据支持继续投资时，完成论文尺度及更强迁移

**理由：** 8192主要增加长时/频谱证据，不应成为开始判断方法的唯一路径；器件和大dt工作应建立在已知正确机制上。

## 四、第一阶段若不足，如何处理，避免另开无穷修复支线

步骤2不通过并不等价于论文第一阶段不可能。最直接外部帮助仍是作者归一化、坐标与数据定义。旧NPZ来源不全时，新生成少量完整元数据比追溯每份旧文件更有效。

本计划不自动授权第一阶段重训扫描。如果顺序试验和作者回复共同指向预训练问题，下一项只能是一次干净的配对预训练：固定一个明确的坐标/归一化解释、同一架构、可审计解析数据与未见测试，从训练loss、未见curl、后续适配代价三处评价。不能只拿四样本过拟合的某个任意阈值做唯一长训入口，也不能把改了数据分布/输出标度的新模型声称为原论文严格复现。具体训练规模与预算须在该证据出现后另立方案；本轮不预先承诺盲训1000epoch。
