### 对前一轮报告的必要纠正

这些纠正针对科学解释，原始轨迹和历史文件继续保留。

1. `128 步严格 Algorithm 1` 应改成 **“128 步逐步尝试重训、允许内层未达标仍推进的变体轨迹”**。只读汇总 run #62 的最终残差，curl-H 为 125/127 个非零子步达标，curl-E 为 105/128；run #66 为 48/63、26/64。执行阶段 P0 将把这次文档审计统计通过脚本正式记账。
2. #62 在零基 step 55–127（人类计数第 56–128 步）两类残差均重新低于其相对阈值，误差仍存在。不能仅凭 #66 后段触顶就判断所有长程误差只由“内层训不动”造成。
3. #62 与 #66 之间同时变更了输出支撑处理和停止阈值；不能把二者全部差异归因于 tol。L3/L4 使用的 checkpoint 训练背景也不同，H-shift 的一次阴性结果不能排除所有位置问题。
4. 前表仍写了当前 nMAE 是论文 MRE 的“约 1.6 倍”，这是跨指标比较，应撤回。论文 `9.6e-3` 在 IV-A 对应 Fig.7 的场比较；当前 128 步末 Ez 全域 nMAE 与该图的时刻、区域、指标均未对齐。
5. `stepgain=1.0986` 来自部分 nMAE 轨迹的对数直线拟合，是描述性拟合数；不是逐步实际放大因子、谱半径，也不能据它证明 `误差必须≤1/N`。
6. 现有 Gaussian 实现 `tau≈32.20 ps，t0≈128.80 ps`，峰值约在人类计数第 43 步。第 5–30 步是源上升段，不能称稳态。V2 排除前四步的窗口是在看到结果后调整的，只能视为探索性分析。
7. 128 步计算预算对应约 `0.394 ns`，8192 步约 `25.19 ns`；末个源采样时刻分别为 `127dt`、`8191dt`。以约 4.24 GHz 基模估计，128 步只覆盖约 1.7 个周期，不能代表长期谐振。
8. “32 cells=31间隔”是有 CFL 数值和本机参考验证支持的候选解释，不是作者已确认；“坐标解码 cell sizes”也不等于作者指定常量 cellsize 通道。

## 2. 明确目标层级与验收口径

先制定门槛，再运行。以下“工程门槛”由本计划提出，不是论文原文承诺。一次失败不能通过事后换分母、删时间窗或改阈值变成通过。

### 2.1 三种状态分别判定

- **流程通过：** 输入/输出位置与时间层正确，训练/更新被记录，轨迹可恢复。
- **内层通过：** 每个被接受的物理时间步中，两个子问题都满足预先登记的最终残差；不能以 `iters<max_inner` 代替残差比较。
- **解的精度通过：** 源外传播、六个场分量、频率和能量与参考在门槛内。运行退出码为 0、没有 NaN、内层 loss 很小，都不能单独代表此项通过。

### 2.2 统一保存的指标

对各 curl 子问题保存 `SSE=sum(error²)`、`MSE=SSE/N_valid`、`target_ss=sum(target²)` 和 `R=SSE/target_ss`，以及逐分量对应值。E/H 物理单位分别为 V/m、A/m；两个 curl 的绝对 SSE 量纲也不同，不能混加后称物理上同一种误差。

当前 `R=1e-4` 对应 curl 相对 L2 `1%`；`R=1e-5` 对应约 `0.316%`。这些是单次旋度拟合误差，不能直接充当最终场误差。

同时采用固定无量纲标度：`L0=0.05 m，E0=1 V/m，H0=E0/Z0，Z0=sqrt(mu0/eps0)`，对应 `curlE0=E0/L0，curlH0=H0/L0`。把物理 SSE、均方及固定尺度无量纲均方都保存。此选择只用于定义与诊断，不声称还原了作者损失。

非零输入但`target_ss=0`时照常计算网络预测，R记null/N/A，停止条件改用固定尺度无量纲MSE`≤1e-10`且最大绝对残差/curlE0或curlH0`≤1e-4`，状态注明`zero_target_fixed_scale`。不自行添加epsilon并谎称相对残差达标。只要目标总能量非零，仍按明确的全量R验收，不删除能量很小的分量；单分量零值的辅助相对指标记N/A。

完整场指标：

- Eq.(5) MRE 使用 `paper_protocol.scalar_metrics` 的严格零值分支，各分量/空间区域分别报告。近零点贡献另列；不把近零点随意删除，不把 nMAE 改名为 MRE。
- Ez 原有全域 nMAE 保留以对接历史，新增六分量的 nMAE 与相对 L2；源点、PEC强制值是否纳入必须在字段名/元数据写清。
- 主要工程误差 `Q(t)=||δF(t)||w / ||F_ref(t)||w`，其中 E/H 分别按 eps0/mu0 与各自 Yee 对偶体积加权，并对齐半时间层；从主统计中排除被强制赋值的硬源自由度。另保存 `||δF||w` 和分母本身。
- 本计划固定比较完成第j次注源后的`(E(t_j),H(t_j+dt/2))`，其中`t_j=j*dt`、j从0起。参考循环末若只有`H(t_j-dt/2)`，用当前参考E执行下一H半步得到对齐的参考H，不重复更新E或加源。`U=||F||w²/2`称交错时间层的离散能量代理，两边用同一约定；不当作精确同一时刻连续能量。P2必须用精确控制验证这个构造。
- 对 `||F_ref(t)||w < 1e-6 * max_t ||F_ref(t)||w` 的弱场时刻，不用瞬时相对误差作通过依据；报告 `||δF||w/max_t||F_ref(t)||w`，门槛 `≤1e-5`。参考最大值来自预先计算的全时长 FDTD，仅用于验收，不能反馈给模型更新/输出还原。
- 源外探针序列：论文位置 `(12dx,12dy,13dz)`，另外两点 `(8dx,10dy,12dz)` 与 `(21dx,19dy,18dz)`。按 Ez 的实际 Yee 偏移作固定空间插值，不把物理坐标直接混成未对齐的数组索引。源值单独记录为输入校验。
- 波形误差采用整段 `||p-p_ref||2/||p_ref||2`，不允许事后平移、缩放或对齐峰值。参考探针序列的峰值低于参考Ez在全域全时长的峰值 `1e-6` 时记 N/A；两者单位同为V/m，不和H或加权范数比较。在进入长程验收前须有至少两个有效源外探针，包含论文探针。

“有效分量”的固定定义：先把E除以E0、H除以H0；某时刻该分量参考L2大于其所属E/H三分量全时长峰值范数的1e-6时，对其使用瞬时nMAE/相对L2门槛。否则只看以所属组三分量全时长峰值为分母的绝对误差，门槛1e-5；严格为零的真值不能靠任意eps构造一个好看的相对误差。体积权重用Yee对偶控制体积：内部dx·dy·dz，落在一个/两个/三个边界面上的半体积因子分别为1/2、1/4、1/8；对不同shape分量按实际物理坐标判定，不能按数组最高索引一律减半。
