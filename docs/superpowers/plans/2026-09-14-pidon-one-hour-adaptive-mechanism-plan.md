- [ ] **启动即写时钟。** `init`记录开始UTC、训练截止=开始+3240秒、最终截止=开始+3600秒、核心/调度器哈希、主权重哈希、矩阵、种子、运行环境和资源，使用exclusive写入。若先手工读文件/开发，也必须先持久记录同一UTC起点；后面init继承，不能延后起计。
- [ ] **直接使用生产回调，不重构训练循环。** `Solver.inner_train`已在opt.step后调用`on_inner_update(which, progress)`。将UTC截止与当前时隙截止比较，返回True则走现有interrupt保存路径。进入每个半步前也检查。不要只在完整物理步外检查时间。

```python
# 核心配置；其余字段复制旧common_config，不改变含义。
cfg = dict(old_protocol['common_config'])
cfg.update(max_inner=3000, inner_time_budget_s=240.0,
           lr=arm['lr'], tol=arm['tol'], strict_stop=True)
# on_inner_update签名已存在；返回True走interrupt，不等同max_updates。
def on_update(which, progress):
    write_throttled_heartbeat(which, progress)  # 最多每10秒一条小JSON
    return utc_now() >= min(training_deadline, arm_slice_deadline)
solver.on_inner_update = on_update
```

`utc_now`用带时区的datetime；`write_throttled_heartbeat`写当前臂、物理层、H/E、累计更新、最近R与更新时间。存储开销不要放大到每次更新保存完整PT。

## 5. 测量与验收：机制、场解、成本分别给结果

每半步：训练objective名称与单位、初始/最终R、SSE/target_SS/MSE、实际更新与耗时、500及以后里程碑、恢复/中断原因。零靶值按既有固定绝对尺度规则，不制造R=0的假分数。可顺带记录字面SSE是否<1e-4，仅作定义敏感性，不用它代替严格场验收。

每完整步：六分量nMAE、MRE单列、绝对MAE、参考峰值与弱场标记、Q、A_fixed、全部已登记源外探针、能量。硬源点不作为正确性成绩。H保持半步对齐。P/R至少对比共同时间前缀；不同可达步数不得直接比较总时长求加速比。

**严格短程通过：** 对该臂实际128个完整步，每个适用半步R<1e-4；参考定义的活跃段Q≤5%、有效分量nMAE≤1%、源外波形误差≤5%、弱场A_fixed≤1e-3。固定使用旧测量掩码和分母；探针尚未获得可解析信号则标INCOMPLETE，不删探针。128通过只称短程，不叫1024/S2或8192/S3成功。

**探索通过：** X臂128步每半步R<1e-3，且相同场标准满足时，只称“宽残差下短程近似场可用”。本臂阈值对应旋度相对L2约3.16%；它不是论文数值，不继承严格臂资格。

若Q/nMAE等场验收越界，保存FAIL状态和证据图，**允许该臂在既定时隙内继续观察至128**。这是这次对调度停止的明确放宽。若Q>1连续5个有效步、出现非有限值或设备/存储异常，停止该臂以免浪费，换独立任务；这个灾难停止阈值不是放宽场验收。

**收益：** P/R同精度、共同长度、相同配置下分别报告更新时间比和更新数比。两随机seed均方向一致且至少省20%才可称“支持旧B筛选”；只有一个seed只能称初步方向证据。初始化、历史预训练成本、I/O另列；资源截断或任一臂场验收不合格不能算正式收益。局部单目标比较单独保留。

**冻结：** 只复制完成128且场检查通过的模型，从零场重新推进同源128，不使用在线场快照或逐时刻权重回放；可复用旧已有安全入口，否则不新写另一求解器。测同机FDTD与冻结推理耗时；若T_infer≥T_FDTD，当前case不存在仅靠多次重用获得时间回本。冻结失败不阻止报告已获得的在线机制证据。

## 6. 失败后的固定任务队列

- S-P在500未过：同一新3000预算内继续，记录500里程碑FAIL；不是申请确认点。
- S-P在3000/240s仍失败：保存并切S-R，不把R取消。
- 一严格臂资源截断：记RESOURCE_LIMIT，保存恢复资格；剩余时隙优先保证另一臂有机会。新协议允许的后续恢复仍扣旧累计预算/绝对时间。
- 严格未同时完成128：按时隙运行X-P/X-R，均从原合法初始化新建；不能把严格失败权重注入X臂。
- 严格两臂都完成128：跑S-R2，避免宽残差支线抢占已成功机制的复核。
- 严格P单目标耗尽：46分钟窗做一次D-LR首层E。仅比较相同首层目标；如果失败发生在更晚时间，这项只能回答首层对lr的敏感性，不能解释更晚失败。D-LR成功仍不构成顺序解。
- 没有适合训练的任务：用原16场生成逐分量/强弱分量图、共同ROI与边界分区误差；修正叠加性测试；整理源外波形和成本。将源码/论文假设差异写清，禁止重新扩充完整G0认证。
- 任何早失败都不自动最终回复。除硬停止，持续推进有前置条件的队列至报告窗口；已全部完成则可以提前交付并解释时间未用满的原因，不无意义等待。
