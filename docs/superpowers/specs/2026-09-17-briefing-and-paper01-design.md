# 汇报素材与论文对齐线设计

## 目标

在不改判既有失败、不追加第二阶段长轨迹的前提下，同时交付：

1. 当前模型的固定权重旋度算子证据；
2. 论文与当前PEC计算路径的逐自由度审计；
3. 一套可编辑、逐步有图、适合电磁场导师审阅的详细PPT；
4. `C:/PI-DON/_01` 中独立的论文显式配置第一阶段参考线，以及服务器部署和运行说明。

## 科学边界

`_01` 不把论文没有公开的内容伪装成“完全一致”。每个配置字段必须属于以下三类之一：

- `EXPLICIT`：论文文字、公式、图表直接给出；
- `DERIVED`：由公开公式和尺寸唯一推出，并保存推导；
- `ASSUMED`：作者未公开，为了可执行而冻结的选择；必须列出替代方案和影响。

主线已有证据与 `_01` 新证据分目录保存。旧权重只读；固定权重算子审计的参数更新数必须为0。精确Yee、解析旋度和边界代数只作为参考或诊断，不计DCO成绩。

## 工作包A：固定权重算子证据

优先复用 `SR-COMPARE` 已保存的模型、测试规格和分数。只在缺少可视化数组时做确定性前向，不重新训练。图至少包含：

- 三分量平面波输入；
- 三分量解析旋度；
- 三分量DCO预测；
- 同色标误差；
- 同一个腔体首个非零E半步的输入、Yee旋度目标及固定权重预测；
- 旧DCO、S1R和随机权重基准的指标表。

随机权重图只用于说明“未经训练的同结构网络”，不与经过在线优化的随机128结果混同。

## 工作包B：PEC计算路径审计

审计对象分为四层：物理条件 `n x E = 0`、Yee自由度位置、损失前预测投影、场更新后的状态投影。输出必须展示：

- 六分量在六个面的切向/法向关系；
- 当前 `apply_pec` 实际清零的数组切片；
- 当前curl-E插入时清零的法向低/高面；
- `loss(P y_hat, y)` 与 `loss(y_hat, y)` 梯度支持差异；
- 哪些与论文文字相符、哪些仍需作者代码确认。

本工作包不修改生产边界条件。只有测试证明具体符号、分量或支持域错误，才另登记修复。

## 工作包C：详细汇报

汇报采用16:9可编辑PPTX。主叙事为：Maxwell与Yee网格 -> DCO为什么是“场到场” -> 第一阶段每一步 -> 第二阶段每个半步 -> 边界和源 -> 指标 -> 已完成实验 -> P/R对照 -> 差异审查 -> 下一步。

每页只讲一个问题，但页数不限。复杂过程采用连续构建页，确保导师能逐步跟随。所有实验数字从JSON/JSONL读取；论文数字标明页码或图表；推导图标明“示意”；尚未完成的项目标明NOT_RUN。

`C:/PI-DON/汇报素材` 保留用户原图，不删除。新图写入 `generated/`，过时或误标图写入索引说明，不覆盖原文件。PPT写入该目录根部。

## 工作包D：`_01` 论文显式配置参考线

第一阶段参考线采用论文直接给出的：32x32x32、1000样本、80/20划分、四级U-Net、Adam、1000 epoch、常数学习率1e-4、batch 32、空间坐标trunk、每分量局部最大值归一化、解析旋度标签。

以下内容必须标为ASSUMED：基础通道数、训练样本中叠加波数量、复数场的实数表示、坐标单位和原点、Yee错位方式、局部最大值的空间范围与物理量还原、损失的精确归约、随机种子。默认实现只是一套最少附加假设参考，不能命名为作者源码复刻。

服务器训练分两段：先运行5个更新的GPU预检，确认形状、梯度、显存、常数学习率和坐标变化；预检通过后才运行1000 epoch。训练实时输出epoch、update、train loss、test MRE、显存和累计耗时。输出包含配置分类、数据规格、源码哈希、best/last权重、完整历史、测试指标和Fig.5固定案例。

## 验收

- 所有新测试通过，原项目测试不因新线受损；
- 固定权重审计明确记录0次参数更新并包lab_log；
- PEC审计能从测试和图中追溯每个被清零的自由度；
- PPTX可打开、文本可提取、每页渲染无溢出或重叠；
- `_01` 在CPU完成小样本预检，在服务器包中不包含旧失败权重；
- 服务器命令可直接粘贴到Anaconda PowerShell Prompt；
- 不启动1024/8192，不修改既有门槛。
