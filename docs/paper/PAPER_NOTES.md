## 一、两个阶段到底是什么（II-C、IV-A、Algorithm 1）

### 第一阶段：训 DCO（III 节）
自由空间平面波叠加 → 解析旋度做标签，监督训练一个改造过的 3-D U-Net。
**这一阶段我们复现了。**

### 第二阶段：PI-DON —— 不是"把训好的 DCO 放进蛙跳跑"

Algorithm 1 的循环体，每一个时间步都做这些事：

```
while N < Nmax:
    Train ∇×H using physics-informed loss     <- 训练，不是前向推理
    Update E using ε and Δt
    Implement excitation
    Train ∇×E using (7) (with boundary conditions)   <- 又一次训练
    Update H using μ and Δt
```

原文 IV-A：**"In steps 4 and 7, the training is terminated when the loss
drops below 1e-4."**

也就是说：**DCO 的权重在每一个时间步都被反向传播更新一次**，直到损失低于
1e-4 才进入下一步。它不是一个冻结的算子在做前向推理。

而式 (7) 这个"物理损失"写出来是什么？是网络输出的 ∇_D×E 与**逐项写死的
Yee 有限差分**之差的平方和。所以每一步的训练目标就是：
**让网络输出等于精确的 Yee 旋度**，误差压到 1e-4 以下。

> 这解释了为什么它不发散：这不是一个学出来的算子在自由演化，而是每一步都
> 被重新拟合回精确差分的优化过程。它本质上是"用梯度下降算的 FDTD"。

代价原文也给了：同一个腔体，**PI-DON 583 s（A6000 GPU）对 FDTD 6.47 s
（i5 CPU）**，慢约 90 倍。

### 评估阶段：这里才是冻结推理（V-C）
训练完成后，"A trained PI-DON solver can accurately model these
uncertainties **without further training**" —— 用训好的 PI-DON 对新参数
直接跑，Δt̃ = 5Δt_max，1000 次蒙特卡洛。**这一步是冻结权重跑时间步进。**

## 二、Fig 8 是什么（IV-A 末）

原文：**"The cumulative loss represents the total loss summed over all
training epochs at each time step."**

- 纵轴 = 该时间步上**训练**所累计的损失（即优化了多少个 epoch 才降到 1e-4）
- 横轴 = 时间步
- 结论 = 用预训练 DCO 初始化，每步几乎不用再训；随机初始化则要训很久

**Fig 8 讲的是"每步要花多少优化量"，不是"场会不会发散"。** 曲线趋近 0 表示
预训练让每步的额外训练成本降到几乎为零，不表示误差趋近 0。

同图里 inhomogeneous cavity 两条线是加了 ε_r=4 介质块后的重复实验，用来说明
多材料不影响预训练的优势。

## 三、论文确实做了稳定性分析（IV-B、Fig 9）

用 **DMD（动态模态分解）** 对 PI-DON 的预测序列做模态分解，看特征值是否都在
单位圆内。设定：Δt̃ = **5 倍** FDTD 的 CFL 上限，采样率 2.48 ppw（接近奈奎
斯特），训练 8192 步、评估 1638 步 → 所有特征值落在单位圆内。

## 四、精度口径：MRE，式 (5)（III-B）

```
MRE = (1/N) Σ |y_pred − y_true| / |y_true|      （y_true ≠ 0）
      (1/N) Σ |y_pred|                          （y_true = 0）
```

**逐点相对误差的平均**。既不是相对 L2，也不是 MAE/max。

> 我们一直拿 nMAE(=MAE/max) 去比论文的 III-D 数字。读到式 (5) 时我判定那是
> 跨口径、把 C9 改判缺数据；**但实测之后证明原来的 nMAE 口径才是对的**，见下。

III-D 的三个数：64³ 4.1e-3 · 64×96×16 3.8e-3 · 32×64×16 4.7e-3。
腔体案例每步 9.6e-3（IV-A）。

### 但「MRE 字面实现」不可能是论文那个数（2026-09-11 实测）

把式 (5) 照字面实现，在 `dco_paper32` 上测得：

| | 式(5) 字面 | nMAE = MAE/max |
|---|---|---|
| EXP 1 | **7.044e-01** | 4.427e-03 |
| 32³ | 3.097e-01 | 4.738e-03 |
| 64³ | 4.962e-01 | 2.875e-03 |
| 64×96×16 | 4.493e-01 | 5.687e-03 |
| 32×64×16 | 7.693e-01 | 6.266e-03 |

字面值是论文 4e-3 的 **40~200 倍**。这不是精度问题：**旋度场处处过零**，
逐点比值在零点附近发散，均值被那些点主导。要让逐点相对误差的平均达到 4e-3，
意味着在真值为零处也要准到 0.4% —— 对光滑振荡场不可能。

而 III-B 写明输出「normalized by the **local maximum for each component**」。
**先按局部最大值归一化再算相对误差，分母就变成局部最大值而不是逐点真值 ——
那正是 MAE/max。** 用 nMAE 比，我们落在论文的 0.70×~1.50×，是说得通的复现。

**结论：以 nMAE 为准，字面式 (5) 作为反证一并保留。** 这个口径我反复过两次
（先说该用 nMAE，读原文后改说该用式 5，实测后回到 nMAE），证据已固定在
`verify_claims.py` 的 `_metric_note()` 里，不再靠记忆。

## 五、两个"论文没写明"其实写明了

> **更正**：C6 原来说「论文没写明 trunk 坐标编码和输入归一化」。**都写了。**

- **III-A**：*"this trunk network decodes coordinate information into cell
  sizes"* → **cellsize 编码是指定的**。所以我们把 `dco_L3b`（abs 坐标）
  标成「论文字面读法」是错的，那个标签已撤。

### 「32 cells」是 32 个点不是 32 个间隔（2026-09-11 更正）

我此前两次说「论文 Δt = 3.075 ps 是 CFL 上限的 1.022 倍，与它自己『训练阶段
受 CFL 约束』的表述不自洽」。**那是我的读法错了，不是论文的错。**

| 读法 | dx | CFL 上限 | 0.99×CFL | 论文 3.075 ps 相当于 |
|---|---|---|---|---|
| 32 个**间隔** | 1.5625 mm | 3.0091 ps | 2.9790 ps | **1.0219×**（越界） |
| 32 个**点**（31 间隔） | 1.6129 mm | 3.1062 ps | **3.0751 ps** | **0.9900×** |

第二行的 0.99×CFL = **3.0751 ps**，与论文的 **3.075 ps** 四位有效数字吻合，
而且 0.99 正是标准安全系数。**论文完全自洽。**

代价是：我们按 32 个间隔跑的那次 2000 步 Algorithm 1，dt 超出 Courant 限，
**参考 FDTD 自己在第 100~200 步之间溢出成 NaN** —— 那次发散是时间步的问题，
不是方法的问题。腔体要用 `--n 31` 才是论文的网格。

## 七、这对我们意味着什么

### 我们做了什么、没做什么

| 阶段 | 状态 |
|---|---|
| 第一阶段：DCO 监督训练 | ✅ 做了 |
| **第二阶段：Algorithm 1，逐时间步物理损失训练** | ❌ **完全没做** |
| 评估阶段：冻结跑时间步进 | ⚠️ 做了（EXP 3），但跑的是**只经过第一阶段**的网络 |

**我们的 EXP 3 = 跳过第二阶段，直接做评估阶段。** 论文从未声称这样可行。
所以 158 步发散**不是"复现失败"，是我们做了一个论文没做过的、更难的实验**。

（我此前对用户说"第二阶段实现了只是跑不动"，**这句话是错的**。第二阶段是
Algorithm 1，我们一行都没写。用户原本的判断是对的。）

### 我们自己那套 ρ 分析还算数吗

算数，但要重新定位。C2/C3/C4/C5/C8 说的都是**冻结算子塞进蛙跳**这个设定下
的规律，它们本身没错，也是论文没做过的分析。但**不能再说"这就是论文的做法
导致 ρ>1"** —— 论文的做法是每步重训。

### AdjPair 的价值反而更清楚了

论文为了稳定，付出的代价是**每个时间步都要重新训练**，因而比 FDTD 慢 90 倍。
如果冻结算子能直接用，速度问题就没了 —— 但冻结算子会发散（我们测了），
除非加结构约束（AdjPair：成对替换，ρ≤1 由构造保证，20000 步不发散）。

**所以我们的工作正好补在论文自己暴露的弱点上**：论文用"每步重训"换稳定，
我们用"结构约束"换稳定，后者不需要重训。这是可以站住的增量。
