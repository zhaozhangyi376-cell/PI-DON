# 脚本分类

- experiments：训练、固定状态、在线求解与实验驱动。
- analysis：审计、结果读取、报告与旧结论验证。
- figures：图与报告导出。
- exploratory：结构化算子、冻结闭环等论文外探索，不能计入原DCO成绩。

很多旧主入口写死历史输出，或者通过根目录glob查文件。为了保留失败和反例，`project/script_registry.json`登记的历史主入口会被run.py拒绝；源码保留可读、函数可导入，主入口并未全部重写成通用接口。

当前可用入口以registry、根README和详细计划为准。新实验创建新入口、显式新输出、绑定行动及lab_log。不要把“旧脚本不能直接跑”说成“原证据不存在”。
