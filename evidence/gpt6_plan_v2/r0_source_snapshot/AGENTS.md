## 2. 论文与证据的解释原则（替代旧版“红线”）

1. 区分 DCO 预训练、Algorithm 1 问题训练、完成训练后的无再训练评估。论文后者包含大时间步与扰动评估；预训练模型直接冻结的失败不能否定完成问题训练后的冻结使用。
2. 式（5）是逐点相对误差；严格零值走原式绝对误差分支。共同归一化不会将它变成 MAE/max。报告逐分量 MRE 与汇总方法，nMAE、相对 L2 仅另列辅助。旧 C9 的“0.70–1.50 倍论文”比较已撤回；旧 EXP2 的随机场/随机间距也不同于 Fig.6 固定案例。
3. Fig.5/6 重建保持物理窗口、波数、方向与同一种子的振幅不变；作者原始振幅、实/复表示等未明之处必须声明假设，不能宣称完全相同数据。当前协议在 `paper_protocol.py`，运行前判据在 manifest.json。
4. III-A 写坐标输入并解码为 cell sizes。直接输入 cellsize 常量张量是本实现选择，不能等同作者坐标编码。III-B 的逐分量局部最大值归一化也不能自动等同当前 RMS。旧权重推理必须保留其训练时归一化；新实现需另做对照。
5. Algorithm 1 的停止阈值 1e-4 必须连同 loss 的求和/平均、单位、归一化解释。当前相对平方损失不能直接与论文 SSE 数值对齐；达到迭代上限后仍推进不能算达标。内层学习率偏小尚非已证实根因。
6. 式（7）的 x 分量印刷符号与标准旋度不符，其他索引也需核对。以 Maxwell 推导和解析测试确定正确符号，并记录对原文的处理，不能机械照抄错号。
7. Fig.8 是每时间步各训练 epoch 的损失总和，不是场误差曲线；仅损失总和变小不能证明优化次数减少。论文 IV-B 的 DMD 是有限轨迹上的模态检查，不是对所有初场和参数的无条件稳定证明。
8. 50 mm、31 间隔和 3.075 ps 是与 CFL 接近 0.99 的候选解释，本轮空气参考验证通过；作者“32 cells”的点/间隔含义仍需核实，不能写成作者已确认。大时间步应与具体更新和训练阶段一起分析。
9. 两点寿命外推、局部谱半径和经验 1/N 关系都不是“冻结算子普遍不可能”的证明。寿命阈值必须统一，爆炸阈值不能称为有效精度寿命。历史 C2–C6/C8 待重审，C7 不利反例继续保留。
10. `dco_paper32.pt` 本轮读到 epoch=260；不能沿用“已确认300轮”。本机日志编号与旧文档引用不一致时明确证据缺口，不补造记录。

下面两条是对这句话的回答，**不要绕过**：

1. **出数的运行一律包 `lab_log.py`**：
   ```
   py -3.11 lab_log.py run -m "这次要回答什么问题" -- py -3.11 train_dco.py ...
   ```
   它记录命令原文、git commit、机器、耗时、每个产出文件的 sha256，写进
   `LAB_NOTEBOOK.md` + `lab_runs.jsonl`。回答的是"这次运行到底发生过没有"。

2. **结论一律进 `verify_claims.py`**，**判据写在数值前面**，然后
   `py -3.11 verify_claims.py --run --md` 刷新 `RESULTS.md`。
   回答的是"这个结论现在还成立吗"。FAIL 是正常结果，不是错误；**反例要和结论
   一起讲**（`RESULTS.md` 里 C7 就是一条标为反例的不利结论，不许删）。

3. **画图的代码要存成脚本**。2026-09-13 吃过亏：PPT 里两张图是某次会话现场敲命令
   画的，没存脚本，下次要改坐标轴只能对着截图猜。现在 `slides/make_*.py` 都在。

4. **图上的每个数字要能说出来源**。`slides/make_p5_evidence_figs.py` 的做法是直接
   `import verify_claims`，调用它算 `RESULTS.md` 结论的同一段代码现场重算 ——

## 6. 下一步（里程碑7：长程瓶颈已定位）

Algorithm 1 已完成32、64和128步逐时间步重训轨迹。当前最佳长程证据是：独立 E/H 网络、每步重置 Adam、lr=3e-4、内层500、相对损失阈值1e-4，128步全程有限，末步 nMAE=1.57e-2；收紧到1e-5可把前30个稳态步压到约2.3e-6，但约第33步后 curl-E 拟合逐渐触顶，64步末nMAE约5.3e-4。H内部Yee平移、L=3网络、梯度裁剪、较小学习率和腔体快照暖启动均未消除同一漂移拐点。完整证据见 `evidence/stage2_longrun/STAGE2_LONGRUN_REPORT.md` 和 `figs/stage2_longrun_comparison.png`。

因此不要继续盲扫 Adam 或直接投入8192步：当前瓶颈是 DCO 输出对逐步变化的 E 场旋度目标的表达/优化约束。若继续，优先做结构性对照（例如显式 Yee 残差或边界/散度约束），并把它标成论文之外的诊断方案；任何新长程结果仍须用 `lab_log.py` 记录并更新 `verify_claims.py`。

数值实验继续包 `lab_log.py`；第二阶段轨迹与报告必须保留逐步JSON和停止条件FAIL。未达到门槛是科学验收FAIL，不等于脚本运行异常。阶段结束按用户要求停下。
