# PI-DON 当前逻辑链示意图

更新：2026-09-16。本图只解释当前第二阶段推进逻辑，不改判旧失败，不把微型通过写成论文长程复现。

## 先分清两个“步”

| 名词 | 通俗理解 | 在当前证据里的例子 |
|---|---|---|
| Adam更新 | 为了让网络拟合当前半步目标，优化器在参数空间里挪一次。很多Adam更新只是在“解一道当前小题”。 | `3769 Adam` 是为了让第一个E半步残差过 `1e-5`，不是电磁仿真走了3769个时间步。 |
| 完整时间步 | 电磁场真的向前推进一次，通常包括H半步和E半步都拟合/接受。 | `4步通过` 是场连续推进了4个完整时间步；每一步内部可能花几十到几千个Adam更新。 |
| 64/128步场门 | 在第64或128个完整时间步检查全场误差、六分量、源点和源外探针。 | 只有64步场门过了，才说明跨过旧57-58步瓶颈；只有128过了才有资格讨论更长。 |

所以，“3769步通过”和“4步通过”不是同一种步。更准确地说：

```text
3769 Adam更新 = 第一个E半步这道小优化题花了3769次参数更新才过门
4 完整时间步 = H/E半步交替成功，真实场向前推进了4次
```

## 为什么要从1个半步、4步、16步、64步这样走

旧失败有两层：

1. **单半步拟合失败**：严格 `1e-5` 下，第一个E半步在3000 Adam时没过门。
2. **场传播积累失败**：旧128残差轨迹虽然残差完成，但真实场在57-58步附近开始明显越线，66步有效分量也越线。

因此推进顺序必须先问小问题，再问大问题：

| 阶段 | 回答的问题 | 已有答案 | 能不能说明论文复现 |
|---|---|---|---|
| `SR-E1-BUDGET` | 第一个E半步是不是预算不够？ | 是，3769 Adam可过。 | 不能，只是单半步诊断。 |
| `SR-MICRO4` | 第一个半步过了以后，连续4个完整时间步会不会马上崩？ | 不会，4步微型场门过。 | 不能，只是短程诊断。 |
| `SR-MICRO16` | 短程能不能扩到16步？ | 可以，16步微型场门过。 | 不能，仍未碰旧57-58步瓶颈。 |
| `SR-64` | 能不能越过旧57-58步场误差瓶颈并在64步过门？ | 服务器正在跑或待回传。 | 若通过，只能说明64步阶段成立。 |
| 128步 | 能不能满足当前登记的128步短程验收？ | 未运行。 | 128过了才有资格谈1024前置。 |
| 1024/8192 | 能不能达到论文长程闭环和频谱级别？ | 未运行。 | 这才接近论文第二阶段长程复现。 |

## 给老师汇报时的一句话版本

我们不是从“失败”直接跳到“复现成功”。现在的进展是：原来严格残差下第一个E半步3000次Adam不够，服务器证明同一目标3769次Adam可过；随后同一严格方案已经从1个半步扩展到4个完整时间步、再扩展到16个完整时间步，并且对应微型场门都通过。下一关是64步，专门验证能否跨过旧实验在57-58步出现的场误差瓶颈。64/128没有通过之前，不能启动或声称1024/8192论文长程复现。
