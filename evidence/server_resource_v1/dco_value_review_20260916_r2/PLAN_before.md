## 验收不变

- 第一阶段同时列历史代码的宏平均nMAE≤1%、样本relL2 p90≤5%和原计划“逐样本≤1%”检查。归约差异必须公开，不能用较宽判据替代较严判据。Eq.(5)MRE独立列。
- 第二阶段非零半步R<1e-4；零靶规则不变。全段活跃去源Q≤5%，有效六分量nMAE≤1%，源外整段相对L2≤5%，A_fixed≤1e-3；弱场沿用原全时长固定参考和绝对门1e-5。
- 当前时刻弱参考与原全时长规则、旧审计门槛覆盖不完整等问题先做测量验证；旧布尔字段不能升级为PASS。
- 1024覆盖300/600/900切片和增长检查；8192五模频率对解析≤0.5%、对匹配FDTD≤0.2%，峰幅≤1dB，活跃能量偏差≤10%。
- 同机同精度P/R两随机对照的Adam和耗时均节省≥20%才支持收益；预训练/评估/失败成本分列。精确Yee、临时吞吐模型不计DCO成绩。

## 执行和交付

本地先行已完成：三次只读行动共0参数更新；五臂JSONL成本与summary一致，8个里程碑指标按原参考精度读回一致。四条旧128轨迹记录中的当前Q在57–58步首次超过5%，有效分量nMAE在66步首次超过1%，不能把残差128解释为完整全时长场认证。S1R 32³已见测试只有1/16样本宏nMAE≤1%，最差样本贡献52.71%的宏误差和。服务器回传显示旧lr1e3在同题四网格均优于S1R，GV100推荐microbatch=8。SR-SHORT-R2回传显示tol=1e-5在第一个E_pending即失败，0个完整接受步；SR-E1-BUDGET回传显示同一首个E目标在3769 Adam达到1e-5；SR-MICRO4回传显示4步严格微型推进PASS_MICRO；SR-MICRO16回传显示16步严格微型推进PASS_MICRO；SR-64回传FAIL，停在第36步E半步拟合失败。低学习率clean64回传PASS_64；clean128完成128步但科学FAIL，失败点为Ex/Ey分量nMAE超过1%而非总Q超过5%。论文式1e-4诊断在64步Q=9.041%失败；随机初始化同规则64步PASS且成本低于预训练clean64，当前证据不支持预训练收益。以上仍不构成128/1024/8192通过。
