# 有界机制与收益验证：最终验收报告

> 实验 ID：`1603692a-4f24-423d-851e-e750ad06dcc2`。协议、门槛、种子、网络、原始权重哈希和资源基线见 [protocol.json](protocol.json)。本报告只解释本轮实际证据；它不把精确 Yee 控制算作 DCO，不把 nMAE 与论文 MRE 混用，也不把中止的 R 臂包装成收益结果。

## 1. 这轮要判定什么

目标不是再把旧任务续跑到 8192 步，而是用一个固定预算的顺序试验回答两个前提：

1. `dco_lr1e3_300.pt` 能否在未见解析旋度场上先达到 S1；
2. 它能否在 Algorithm 1 的第一个非零拟合中，于 500 次 Adam 更新内达到物理相对残差 `R < 1e-4`。

只有两个前提都成立，才允许比较 P（预训练）与 R（随机）在 64/128/1024 步的成本，并继续做冻结复用和 8192 步。因此，失败后停止是方案要求，而不是因结果不理想而缩短试验。

共同条件为：31 个腔体点、边长 0.05 m、`dt=3.075 ps`、`h_shift=True`、L4/base32、cellsize 坐标、RMS 输入尺度、独立 E/H 网络、Adam `lr=3e-4`、每次非零拟合最多 500 次更新和 360 s。P 使用已登记主权重（SHA-256 前缀 `3f259bc887a10fac`）；R 使用种子 20260914 的随机初始化。

## 3. P 首次失败是否只是接口、尺度或边界错误

对 P 第 0 层失败时保存的原始参数做了独立纯前向复算，结果如下：

| 核对项 | 结果 |
|---|---:|
| 运行记录的总 R | `0.0005160257095534574` |
| 磁盘参数重算的总 R | `0.0005160256872819171` |
| 二者绝对差 | `2.23e-11` |
| x / y 分量 R | `3.9837015e-4` / `3.8636339e-4` |
| z 分量 | 靶能量为零，故不伪造相对 R；其绝对最大误差为 `2.1523569e-7` |
| DCO 输入核心 | `3×31×31×31`；RMS 尺度 `3.5892417e-10`；`Lc=0.0016129033` |
| DCO 裁剪后未覆盖面 | 三个高端 PEC 面均为零；没有隐藏的非零 Yee 回填 |

因此，在本次有界诊断覆盖的“记录一致性、三分量、RMS 尺度、支撑裁剪与 PEC 边界回填”范围内，没有找到一个能把 P 的失败解释为接口错误的因素。这不是“实现已经完全正确”的证明；它只排除了这几个具体且高优先级的替代解释。

## 4. 对机制与收益的结论

当前证据支持以下狭义结论：**这个已登记的第一阶段权重既没有通过本轮未见解析场的精度门槛，也没有使 Algorithm 1 的第一个非零拟合在固定预算内收敛。因此，没有证据表明它为第二阶段带来可验证收益。**

R 在第 0 层比 P 更快通过，方向上不利于“该预训练权重提供暖启动”的假说；但 R 只有一个种子、轨迹在第 26 步后被提前终止，且没有成本对照的第二种子，所以该现象不能升级为“预训练无益”的定量结论。

这同样不能推出论文本身错误。论文第二阶段依赖每个时间步的再训练，而论文没有充分给出可直接确定本实现内层优化可达性的全部细节。本轮能确定的是：以此权重、此表示、此严格残差和此预算，第二阶段的机制前置条件未成立；继续跑 8192 步不会回答论文方法是否有效，只会制造不合格轨迹。
