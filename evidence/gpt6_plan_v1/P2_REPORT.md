# P2：Yee/Maxwell 接口与精确控制报告

## 运行前门槛

P2 要求常量、线性场和离散平面波符号正确；所有更新目标有明确归属；128 步 float64 精确控制加权误差不高于 `1e-10`、float32 不高于 `1e-4`，并且必须标为“精确 Yee 控制，不是 DCO 成绩”。

## 坐标、形状与时间层

| 量 | 数组形状 | 物理位置（以 `dx,dy,dz` 为单位） | 更新/支撑 |
|---|---|---|---|
| Ex/Ey/Ez | `(n,n+1,n+1)` / `(n+1,n,n+1)` / `(n+1,n+1,n)` | `(1/2,0,0)` / `(0,1/2,0)` / `(0,0,1/2)` | PEC 后的 E；Ez 硬源写入后参与 curl-E |
| Hx/Hy/Hz | `(n+1,n,n)` / `(n,n+1,n)` / `(n,n,n+1)` | `(0,1/2,1/2)` / `(1/2,0,1/2)` / `(1/2,1/2,0)` | H 半时间层 |
| curl-H | `(n,n-1,n-1)` / `(n-1,n,n-1)` / `(n-1,n-1,n)` | E 的可更新内部支撑 | 网络 cube 覆盖全部目标自由度 |
| curl-E | `(n+1,n,n)` / `(n,n+1,n)` / `(n,n,n+1)` | H 位置 | cube 覆盖前 `n` 层；余下高侧面由 PEC 推导为严格零，代码显式置零 |

当前 PI-DON 顺序是 **E 更新 → 硬源 → H 更新**。原 `PECCavity.step` 的顺序为 H 更新 → E 更新 → 源，因此 P2 的精确控制构造了同一 `E→源→H` 顺序的参考，避免把半时间层错位误判为 DCO 误差。

## 结论边界

P2 通过说明当前网格形状、符号、PEC 高侧支撑和选择的半时间层参考可以相互一致。它**不**评价网络拟合，因而不能写成 PI-DON/DCO 成功。下一步 P3 只允许用此已验收的接口，对固定 FDTD 状态分别测量内层可拟合性。
