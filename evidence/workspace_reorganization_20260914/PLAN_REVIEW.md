# 下一轮直接推进计划的独立审查

日期：2026-09-14。范围：只读审查 `mechanism_2h_v1`、`mechanism_1h_v2`、机制收益复核、夜间末层诊断，以及实际 `pidon_solve.py`、`dco.py`、`mechanism_hour_runner.py`。本审查没有运行训练、修改求解器或重新计算科学数值；本文数字均引用原始记录。以下是供总计划吸收的建议，不能把建议记作已执行。

## 1. 唯一目标，以及现在缺的不是同一件事

工程目的应写为：用可追溯的实验，判断本文所主张的“学到旋度算子 → 逐时间步适配求解 → 得到可靠电磁场 → 训练或复用是否有收益”能否在明确的实现假设下成立，进而判断是否值得作为研究方向。根目录清理、认证、绘图、优化器尝试都必须指向这条链中的一个缺口。

| 待回答问题 | 当前证据 | 尚不能得出的结论 |
|---|---|---|
| 第一阶段是否学到了旋度 | 原16例中12例宏nMAE≤1%；最差例宏误差被弱z分量主导；迁移失败 | 不能称全面不会求旋度，也不能称论文第一阶段已验收 |
| 在线每步训练能否推进 | S-R有33个严格残差合格的完整步；第34候选E在3000更新失败 | 不是严格64/128成功；也不是网络表达能力不可能 |
| 当前预训练权重是否帮助在线优化 | 原首个非零E，P的500更新仍失败，R的95更新通过；完整匹配窗口收益缺失 | 不能宣布预训练总体有益或无益 |
| 高学习率能否解决 | 特定P初始化、Adam继承、lr=1e-3的D-LR4在第2候选E失败 | 只能否定这个设置；不能泛化成所有高学习率都无用，更不能锁定唯一根因 |
| 训练后能否冻结复用并回本 | 尚无合格长程在线模型的独立复用与同机成本证据 | 不能承诺加速，也不能用未问题训练模型的旧冻结失败否定论文 |
| 与论文是否一致 | R定义、坐标编码、归一化和权重使用方式仍有声明假设 | 本项目R<1e-4始终不是已经确认的论文loss<1e-4 |

第一阶段门槛、在线机制门槛、收益门槛应分栏判定。第一阶段FAIL不能取消独立随机初始化在线机制试验；B/U无收益也不应再次自动阻断用户明确要求的长程机制验证。长程能跑通但没有加速价值，是有用的研究决策结果。

## 2. 对“两小时却十二分钟结束”的判断

报告所述S-R的失败定位有依据：第34候选H已到9.9361e-5，E的3000更新终值约1.25044e-4，最后接受场尚未整体爆炸。D-LR4的失败同样有原始半步记录。但这只完成了一个优化候选的否定和一部分审计，不能叫两小时计划的所有有效任务已完成。

原计划的S-P恢复、源外波形/成本、模型参数前向复核等未全部有结果。恢复可能确实不合法，但必须给出证据后将其标为BLOCKED/NOT_RUN，不能由一句“资格True”同时推定可恢复又不解释为何跳过。要用任务队列替代“这个门槛没过，所以整轮结束”。

S-P-retry尤其需要核实：summary的10447更新来自6个完整步，但heartbeat已经记录其后H的183更新。检查点指针是提交序号5。仅凭这些文件不能确认检查点包含这183次，以及心跳后是否有未知尾部。若最新安全checkpoint仅含6个完整步，从那里重做第7候选会丢失已消费预算；这不满足原恢复约束。即便参数齐全，旧一小时绝对截止已过，旧协议自身也没有新的运行时授权。最直接的处理是保留旧RESOURCE_LIMIT，另建合法新臂，而非围绕旧恢复资格再做一轮工程。

## 3. 第一性原理能排除什么，不能排除什么

实际网络接受固定半步输入，产出旋度；目标是已知Yee旋度。每个半步本质上是一个确定性、全批次非线性最小二乘问题：

`R(theta) = sum ||DCO_theta(F) - curl_Yee(F)||² / sum ||curl_Yee(F)||²`。

在输入F固定时，分母和输入归一化尺度均固定。当前RMS输入及其逆变换是本实现的表示选择；同一个半步内它不构成随机目标。优化失败可能来自：输入未包含必要信息、目标/位置接口错误、当前特征空间不足、非线性优化停滞、继承的Adam状态与新目标不适配、精度/尺度问题。现有证据尚未区分后四项。

R=1e-4对应旋度相对L2=1%。它既不是场误差1%，也不保证误差不会累积。因此每半步残差与源外场验收必须并列。硬源点被直接赋值，源点相符不构成传播成绩。Hz的巨大nMAE必须和接近零的参考量、绝对误差并列，不得删除，也不得用其巨大比值单独宣称总体失控。

当前最后一层是`Conv3d(32,3,1)`；冻结特征后，它仅是33个系数的线性拟合。因此一次float64 QR/SVD投影，可以检验“这组特征下，末层是否已经接近最佳”。若投影过门，优先怀疑当前末层优化；若不过门，只证明这组冻结特征不够，不能证明整个网络类别不够。旧43/96固定状态的末层诊断已做过，不应原样重跑；新诊断必须使用实际S-R第34候选这一不同问题。

## 4. 推荐执行粒度：一个决策队列，一条连续轨迹

新计划不设1h/2h的会话截止；为每个实验登记有限更新和存储上限。预算是上限而非成果，失败后切换独立任务；完成全部已登记任务才结束。每个64/128/1024节点自动生成报告、继续满足前提的同一轨迹，不例行等待确认。

### T0：只解决本次真会用到的证据缺口

理由：避免从不可恢复状态起跑，或用显示错误掩盖科学失败。

- 审清S-P尾部；未保存即标UNKNOWN/不可严格恢复，不补造精确总数。
- 记录器需在受控interrupt时保存pending输入、目标、当前参数、Adam/二阶状态、已消费更新和时间；双槽滚动即可。
- 科学状态与进程exit分别保存。None显示错误不能吞掉已保存的科学FAIL，也不能自动赋予恢复资格。
- 汇总更新来自去重的实际计数，不能再用顶层0；同时分别保存已接受更新、失败候选更新、基础设施重试成本、未知尾部。
- 只跑实际改动的针对性回归，不重新扩展G0、历史全资产认证或新调度框架。

### T1：一次鉴别当前真实失败，不做优化器扫参

理由：下一次变化需要回答一个具体因果问题。

至多检查三个已有固定输入：P首非零E、S-R第34候选E、该候选H。复用已有原始张量，核对生产前向R、分量误差、目标能量、输入尺度和必要邻点；对E目标做一次冻结特征最小二乘，保存残差和秩/条件信息。必要时检查两个预登记方向的梯度一致性；不得把“梯度非零”当作“优化已正确”。旧失败模型仅供诊断，不得写回生产或继续旧轨迹。

这一步的交付是选择一项最有依据的新优化规则，或写明尚无法区分。未知原因不自动取消后续合法新连续试验。

### T2：至多两项新优化规则，每项直接请求128完整步

理由：单一首层、4步、16步都避开了已知第34候选，不能回答当前主要问题。64是中间检查，128是首个短程交付。

保持网络、物理网格、源、dtype、h_shift、尺度和R/场门槛。新实验均从原始master或新随机权重、零场开始；不得恢复旧FAIL或从第33步后拼接。每项规则在第一次更新前冻结全部分支和更新上限，500/3000只作新协议中声明的观察点或配额点。

建议优先在以下两种机制上作有限选择，而非继续增大固定学习率：

1. **全批次最小二乘优化候选**：利用已有Adam→strong-Wolfe L-BFGS路径，按新协议给足明确的补偿预算；只改变求解这个固定目标的数值方法，不改变目标、网络输出或场更新。已有P4-A固定冷启动失败应保留；新顺序暖启动是另一实验。closure、成功参数提交、回滚和Adam次数分别计数；不得混成同一种“更新”。
2. **优化器状态候选**：若需要，单独检验每个新物理目标重置Adam状态的效果，权重沿时间继承。源码已有`reset_opt_each_step`，优先复用。重置Adam不是重置本目标预算：累计配额由实验台账持有。不得把它和学习率、归一化、网络结构同时改变。

建议将每非零半步新预算设为“最多3000次Adam，第一候选另最多1200次L-BFGS closure”，具体总提交数限制在协议中展开；不沿用240秒这一旧机器时隙门槛，但真实耗时必须报告。以上是**新方案建议配额**，不是改变旧臂门槛。若主计划采用另一数值配额，必须在运行前统一冻结，不得读完某候选结果再加码。

先让新随机臂检验在线机制，预训练臂作为独立配对对照继续执行。两者失败原因分别记录；P失败不能取消R，R失败也不能取消P。候选1失败才执行候选2，两个都失败仍完成T3/T5和研究判断，不立刻结束会话或追加第三候选。

### T3：补齐第一阶段最直接的对照，独立于T2成败

理由：用户目标包含第一阶段；不能无限围绕E拟合而永久搁置“是否学到可迁移算子”。

先将已有16例的原始预测和完整波参数做固定汇总，保留S1旧FAIL；检查实际训练目标、归一化、坐标和推理恢复是否同一合同。若发现确定接口错误，只做这一处修复并从合法原始起点开一个新训练版本。若没有确定错误，避免再做四样本过拟合门槛/多种trunk修复；登记一次干净、有限的完整训练与未见验证作为独立任务，训练/验证/盲测试分开，模型只按验证集预定准则选取，盲测试只最终运行。训练规模、epoch/update总预算必须明确写在主计划后才能执行，不能以本段含糊授权自行选择。

同时保留旧master对照，逐分量报告式(5)MRE、nMAE、绝对误差和参考峰值；固定连续波场重采样作迁移，避免换网格同时换场。第一阶段新权重通过后，再按T2胜出规则作P/R共同128窗口；没有通过也如实保留在线随机臂机制结果。

### T4：自动64→128→1024→8192，不把局部成功变成反复开门

理由：目标是完整物理过程；已合法的同一轨迹不应反复从零训练制造碎片。

| 节点 | 必须成立 | 失败后行为 |
|---|---|---|
| 64 | 从零场连续64完整步；每适用半步R<1e-4；零靶值固定绝对规则；Q≤5%、有效分量nMAE≤1%、已可解析源外波形≤5%、A_fixed≤1e-3 | 本臂失败，不续它；转独立候选或第一阶段/成本任务 |
| 128 | 同一轨迹完整128且同上；已登记探针全部有足够可解析信号，否则INCOMPLETE | 不能升级1024；保留已接受前缀但不称短程全部PASS |
| 1024 | 同一轨迹连续1024、同上场门槛；300/600/900切片；原末128步RMS-Q相对前128不超过2倍的延长风险规则 | 未过则8192为NOT_RUN；不以接参考场或短窗拼接救场 |
| 8192 | 1024合法通过、未失败的同一轨迹可恢复；全程原场门槛；五模频率相对解析≤0.5%、相对匹配FDTD≤0.2%，可解析峰幅≤1dB、活跃能量偏差≤10% | 分别给残差、场、频谱结论；缺峰或缺时段不可算PASS |

所有数值门槛继承既有机制计划；活跃/弱场掩码和分母由参考固定，不能根据DCO输出删点或改取峰窗口。64的无信号探针不能算波形通过，也不必阻止按预登记规则继续观察到128；正式短程通过须在128补齐可解析观测。若因此采用“64残差/场通过，波形待128”的状态，须在开始前写清，不能临时改判。

旧33接受步不是新64门槛的证明；它只说明新连续试验至少应跨越已知困难区。当前nMAE小也不取代Q、源外波形和弱场判据。

### T5：直接回答研究价值，在线能解不等于值得用

理由：所有逐步靶值本来可由Yee直接计算，在线每步重新拟合可能昂贵。研究价值需要额外优势。

- P/R共同长度、同精度报告真实更新时间和更新数；两个随机seed一致且两者均省20%才沿用已有B筛选PASS。初始预训练成本单列，失败/截断不用无限加速比。
- 对完成问题训练的合格模型，复制最终H/E权重、从零场重新做同源128→1024冻结试验；通过再做一次脉冲宽度×1.2的独立波形。无法通过就报告该“最终权重冻结”解释无效，不直接否定作者可能不同的权重使用方式。
- 同机FDTD、在线DCO、冻结DCO分别计时，不能CPU与GPU混算加速；若冻结推理不比FDTD快，重复调用次数再大也不会仅靠时间摊销回本。
- 准备作者澄清材料可以继续，未经用户授权不发送消息。论文原始代码、完整训练细节和作者真实评估算法，不能通过本地继续扫参自行确认。

## 5. Harness必须防止的行为

每个任务必须有：目标缺口ID、待区分假设、不可变参数/门槛、允许使用的初始化、真实计数来源、证据目录、成功后的下一任务、失败后的独立下一任务。没有这几项，不启动新出数。

总计划用一张状态表同时呈现：论文对齐、S1、短程、1024、8192、B、U，不能用“工程已完成”“脚本已运行”覆盖科学状态。工程任务只能证明实验链可信，不自动增加复现完成度。

明确队列终止条件：用户叫停；设备/存储无法安全保存；所有预登记训练及独立诊断/报告已完成；必须改变物理含义或网络类别而超出新计划授权。单臂FAIL、旧认证缺项、源点很准、当前有33步、临时没有stdout，都不应成为整轮终止或升级成绩的理由。

当前最直接的主线是：**修复本次计数/恢复最小缺口 → 固定真实失败目标作一次优化鉴别 → 最多两条合法新连续128轨迹 → 自动长程验收；并行补第一阶段和成本/复用问题。** 结构化Yee残差、精确卷积、散度投影是有价值的其他研究方法，但除非作为新结构明确另立目标，不应混入本轮论文DCO成绩。
