# v3 执行核查：预登记的只读/隔离反例

本次不续训正式 DCO，不改生产实现，不覆盖旧证据。所有测量由 lab_log 包装。

1. 将真实精确控制的 rows 缩为一行，或把数值误差改坏但保留布尔标签；合格的完整 G0 验收器必须拒绝。
2. 模拟 JSONL 已 fsync、metadata 尚未提交时崩溃；恢复后新序号必须不重复，并识别未提交尾部。
3. 以 CPU 极小随机网络模拟 nonfinite/resumable=false 的终止态；训练入口必须拒绝再次更新。
4. 分量相对损失与物理总 R 故意分离；正式容差必须由物理总 R 判定。
5. 核对 54 条测试记录的独立 ID 数、双精度参考在实际测量入口的 dtype。
6. 只读旧四个权重、Adam 状态、预测/靶值与训练轨迹，复算 R、分量/边界残差及实际更新。
7. 记录磁盘余量、checkpoint 尺寸与既有权重 SHA256，给夜间计划制定资源预算。
